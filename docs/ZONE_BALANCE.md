# Zone balance (step 165, 0.1.4-prealpha)

Counts come from `data/levels/*.toml` (generated by `tools/expand_maps.py`). Camps respawn
after 10 min away or on a zone reload (the Breach side challenge after 15 min). Chest tiers
set the loot rarity floor in `ZoneChests.FLOOR`: normal = basic, hidden = uncommon, vault =
rare (a vault chest stays locked until its lever group or boss flag is set).

| Zone | Size (m) | Camps | Encounters | Chests (normal / hidden / vault) | Waystones |
|---|---|---|---|---|---|
| Eldoria town square | 240 x 240 | 0 | 0 | 5 / 2 / 0 | 1 |
| The Old Oak | 160 x 160 | 0 | 0 | 0 / 0 / 0 | 1 |
| Mage Association | interior | 0 | 0 | 2 / 1 / 0 | 0 |
| The Landfill (Midden) | 700 x 600 | 8 | 0 | 21 / 2 / 1 | 2 |
| The Breach | 220 x 320 | 1 (side wing) | 6 rooms | 3 / 1 / 0 + the Warden vault | 1 |

Density: the Landfill has about 19 camps per km² and one chest per 17,500 m², so a camp or
chest sits within about 60 m of every road. No camp or loot numbers changed this release.
Hand tuning after real playtests is a carried-over gap.
