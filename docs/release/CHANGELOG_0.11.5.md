# Changelog: 0.11.5-prealpha

The in-game build string is `0.11.5-prealpha`. The menu name is Pre-Alpha 0.11.5.

## 0.11.5

The main quest trail runs from the tutorial through Act V.

The Breach ends when the Breach Warden dies. That opens the vault and the Labyrinth gate. The Blightmaw Matriarch is Act II only. An old save that was still waiting on her finishes if the vault was already open, and otherwise waits on the Warden.

Act I is The Goblin Warrens: kill the Goblin King. Act II starts from his death. Act III starts from the Matriarch. Act IV and Act V stay kill-the-boss quests. The marker stays on the earliest open main step. A waypoint marks the vault dais, the next stair, or the gate that leads there. Entering Bob's lab counts as finding the Old Oak.

The Core stays closed. Music stays silent. Save version stays 1.

Co-op protocol 7.
