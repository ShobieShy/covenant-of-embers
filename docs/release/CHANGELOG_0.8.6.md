# Changelog: 0.8.6-prealpha (2026-11-11)

Everything since 0.8.5-prealpha. SaveGame stays on version 1.
The in-game build string is `0.8.6-prealpha`.

## 0.8.6

- An action skill on Q. One 30 second cooldown. It does not fire while you are down.
- The verb follows the element tree you have spent the most points in. A tie breaks toward Arcane, then Fire, Water, Earth, Air, Light, and Dark.
- Light summons. Dark converts. Fire and Earth stagger. Air, Water, and Arcane chain.
- In co-op the host applies the cast, so the joiner sees the same result.
- Dash moved from Q to V. The action skill is on the rebind list.

## Still not in

- 0.8.7 shields, flask, relic, and extra staff bases.
- Covenant Escalation as a playable dial. The code is still `Vigil`.
- The Abyss and Endless Descent.
- Act IV.
