# Changelog: 0.11.6-prealpha

The in-game build string is `0.11.6-prealpha`. The menu name is Pre-Alpha 0.11.6.

## 0.11.6

A backpack item can be marked junk with J, the Mark junk button, or a right-click menu on its slot. Favorite sits on the button next to that, and on the same menu. A favorite is kept out of Sell all and Sell all junk. The two marks do not both stick.

The shop has Sell all and Sell all junk. Each one asks first and shows how many items and how much gold. Keep, or Esc, leaves the shop open and pays nothing. An empty sale says so and does not ask. One selected row still sells immediately.

Basic loot picked up off the ground can be marked junk from the settings. That checkbox starts off. Buying, crafting, and loading a save do not mark anything by themselves.

Marks are saved with the character. Save version stays 1. An old save with no favorite field loads with nothing locked. Co-op protocol stays 7. The seller's own gold is what changes.

Music stays silent.
