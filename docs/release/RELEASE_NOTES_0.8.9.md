The Abyss, then Endless Descent.

**What's new since 0.8.8-prealpha**
- After you beat a labyrinth's story boss, you can run that labyrinth again. While you are still finishing that replay, it is the Abyss.
- After you beat the Abyss, there is no last floor. That is Endless Descent. The new floors are generated. The story floors stay as they were built.
- Endless depth raises how high you can set Covenant Escalation. You can set it from 0 up to that cap, not above it. In the code the dial is still Vigil.
- A deeper tier's gear can show up in a normal story run. It keeps its effect and is scaled to the story floor. The rate is not tuned yet, so a normal kill does not add one until that number is set. In co-op, each player rolls their own.
- This is not The Forgotten Abyss. That name stays the run after the Core.

**Your saves.** Saves still load (save version 1).

**Known issues**
- Music is silent.
- Staff sounds, Bob's look, and the scavenger's lines are placeholders.
- The door after Forgemaw does not open Act IV.
- Act IV, The Sunken Ruins, is not playable yet.
- In co-op, the joining game can still close with an error code (134) on exit. Your progress is already saved.
