A polish update. The game looks, sounds and feels smoother, from the main menu to the
Labyrinth stairs.

**What's new**
- Panels fade and slide, menus react to hover, and save slots are cards.
- Hold Interact to take the Labyrinth stairs. In co-op, a vote banner shows who is ready.
- Typewriter dialogue, with an Instant text option.
- Livelier HUD: bars pulse, gold counts up, damage numbers merge, and loot comes to you.
- Enemies flinch when hit, casting has more weight, and there is a death camera.
- Fast travel from the world map, with a confirm card and new loading-screen art and tips.
- Clearer co-op joining: you can see each join phase and when the host is still loading.
- New sounds for menus, chests, shrines and stairs.

**Fixed**
- Fast travel out of the starting building no longer sends you back to town.
- Party frames no longer cover the HUD, and the co-op panel is centred.

**Your saves.** 0.3.0 saves carry over unchanged.

**Known issues**
- In co-op, the joining game can close with an error code (134) on exit. Your progress is already saved.
- Save-slot cards don't show playtime yet.
- The first Labyrinth floor can hitch once while its shaders compile.
