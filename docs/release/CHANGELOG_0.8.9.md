# Changelog: 0.8.9-prealpha (2026-11-11)

Everything since 0.8.8-prealpha. SaveGame stays on version 1.
The in-game build string is `0.8.9-prealpha`.

## 0.8.9

- After a labyrinth's story boss, that labyrinth can be run again. That finite replay is the Abyss.
- Beating the Abyss opens Endless Descent: more generated floors, no last floor. Story floors stay the handmade kits.
- Endless depth raises the Covenant Escalation cap, and the dial can be set from 0 up to that cap. The code is still Vigil.
- Gear from a deeper tier can appear in a story run. The part keeps its effect and is marked with the story floor. The rate is unset (0) until it is tuned.
- Each player rolls that drop from their own stream. It does not change the kill roll.
- The Forgotten Abyss is still the post-Core run. This mode does not rename it.

## Still not in

- Act IV, The Sunken Ruins, as a walkable act. The choice is The Sunken Ruins. It is the next release.
