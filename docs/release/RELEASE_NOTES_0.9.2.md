Main quests, side quests, and one tracked quest.

**What's new since 0.9.1-prealpha**
- The HUD follows one quest. A new main quest takes that slot. Joe's Marks and Joe's Seals do not, unless you press Track.
- Missions has Main, Side, and Completed. The card shows the reward and a recommended level.
- When a quest finishes, a short card shows the name, the XP, and the dust. The game does not pause for it.
- A mark in the world and on the minimap points at the tracked step when the game already knows where that step is. During the prologue the gold mark you already follow is the only one.
- The Sunken Ruins is a main quest. After Forgemaw, it asks you to face the Drowned Choir. There is no new conversation.
- Bounty counts are saved. A co-op character file can carry side quests and bounties. It does not carry the host's story.

**Your saves.** Saves still load (save version 1). An old save with no tracked quest follows the first active main quest.

**Known issues**
- Music is silent.
- Staff sounds, Bob's look, and the scavenger's lines are placeholders.
- The halls are grey boxes.
- In co-op, the joining game can still close with an error code (134) on exit. Your progress is already saved. The joiner's screen does not yet mirror the host's tracked quest live.
