# Changelog: 0.9.1-prealpha (2026-11-12)

The Echo menu. One pause screen for the menus that used to be separate. SaveGame stays on version 1.
The in-game build string is `0.9.1-prealpha`. The menu name is Pre-Alpha 0.9.1.

## 0.9.1

- Esc opens the Echo menu and pauses. Esc closes it. Q and E change tabs while it is open. Q in the world is still the action skill.
- Tabs, left to right: Map, Missions, Inventory, Skills, Character, Challenges, Social, Settings.
- Tab, K, and M open the menu on Inventory, Skills, and Map.
- The tab underline slides, and the page fades. Reduced motion (the existing setting) makes that instant. High contrast draws a thicker underline.
- The quest tracker stays on the HUD and still lists every active quest. It sits on the left, clear of the minimap.
- Missions reads the quest log that already ships. Character shows the numbers you already have. Challenges lists the bounty rows. Counts last for the session and are not saved yet.
- Vendor, the assembly station, dialogue, and the title screen stay where they were.
