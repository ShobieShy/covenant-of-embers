# Changelog: 0.8.8-prealpha (2026-11-11)

Everything since 0.8.7-prealpha. SaveGame stays on version 1.
The in-game build string is `0.8.8-prealpha`.

## 0.8.8

- Covenant Escalation can be set after Forgemaw, from 0 to 10. The code is still Vigil. Tier 0 is the story run and does not change Act II or Act III.
- Enemy health, damage, and drop weights follow the Vigil curves. An uncleared floor still cannot be remixed.
- Town Square and Old Oak have a Breach-key chest, a vendor, and a slot machine. They spend a breach key or gold.
- A bounty board pays gold for repeatable kills of enemies that already ship.
- A mantle is cosmetic. It has no stat.
- Enemies say a line when they chase, when they are hit, and when they die.

## Still not in

- The Abyss and Endless Descent as a mode you can walk.
- Act IV, The Sunken Ruins.
