The Echo menu.

**What's new since 0.9.0-prealpha**
- Esc opens one menu. The tabs are Map, Missions, Inventory, Skills, Character, Challenges, Social, and Settings.
- Q and E move between those tabs while the menu is open. Out in the world, Q is still the action skill.
- On a pad, the shoulder buttons move tabs. On the skill tree, once a skill has focus, the shoulders move between trees the way they did before.
- The underline and the page animate. If reduced motion is on, they snap.
- The quest list on the HUD moved to the left so it no longer sits on the minimap. It still shows every active quest.
- Missions, the map, inventory, skills, and settings are tabs of this menu. Tab, K, and M still jump to those three.

**Your saves.** Saves still load (save version 1). Bounty counts are not written into the save yet.

**Known issues**
- Music is silent.
- Staff sounds, Bob's look, and the scavenger's lines are placeholders.
- The halls are grey boxes.
- In co-op, the joining game can still close with an error code (134) on exit. Your progress is already saved.
