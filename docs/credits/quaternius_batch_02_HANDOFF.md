# HANDOFF — batch_02_characters (for Luna)

All characters are Quaternius low-poly rigged GLBs in one shared style. Every one uses the same `CharacterArmature` rig, so the animation clips are interchangeable and can be retargeted or shared through an AnimationLibrary.
Standard clip set (24): Idle, Idle_Neutral, Walk, Run (+Back/Left/Right), Wave, Interact, Idle_Sword, Sword_Slash, Punch/Kick L/R, Roll, HitRecieve(_2), Death, plus Gun_* clips (ignore those).
The Quaternius figures are taller and more realistically proportioned than the chunky Kenney town kit. Adjust scale to match the doors (roughly 1.7–1.8 units tall). Each folder includes a `_preview.jpg`.

## Gaps (nothing fit well, so nothing was forced in)
- **Nerd:** no CC0/CC-BY rigged bookish or robed scholar in a matching style. Workaround: recolour Adventurer_male and attach a book or glasses prop.
- **Buff:** no clothed, muscular fighter in a matching style (the only "Male Fighter" was an untextured shirtless base).
- **Loli (petite young mage):** no suitable model. The available young or petite figures are either a different chibi style or adult figures. Recommendation: commission or kitbash a modestly dressed small mage later, e.g. from Quaternius Ultimate Modular Characters, whose Google Drive download was rate-limited today, or scale Adventurer_female down with a long robe. Keep the design non-sexualized.
