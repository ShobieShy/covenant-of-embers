# Layout specs

Normalized coordinates taken off the paintings in [docs/maps/levels/](../maps/levels/). x is west to east. y is north to south. A circle on the painting is a circle in the world.

| File | Covers |
|---|---|
| [LEVEL_SPEC_TOWN_LANDFILL.md](LEVEL_SPEC_TOWN_LANDFILL.md) | Eldoria and the Landfill, plus the rules for every level |
| [LEVEL_SPEC_ALL.md](LEVEL_SPEC_ALL.md) | Association, Old Oak, Bob's lab, Breach, Acts I–IV, and the Inverted Spire |

Builds use these files and the paintings next to them as the underlay. The overlay check is a top-down of the level at half opacity over the painting. The outline, the paths, and the landmarks have to sit within about 5 percent of the map width. A cutaway painting also needs a plan of each floor and a side elevation.
